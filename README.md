# Lab01 ร้านโน้ตบุ๊กสามแบบ

เปรียบเทียบการสร้างหน้าเว็บแบบ SSG, SSR และ CSR โดยใช้ข้อมูลสินค้าจากฐานข้อมูล SQLite ชุดเดียวกัน

ผู้จัดทำ: นางสาวสิริรดา หงษ์แสงไทย รหัสนักศึกษา 673380022-4  
สาขาเทคโนโลยีสารสนเทศ วิทยาลัยการคอมพิวเตอร์ มหาวิทยาลัยขอนแก่น

## เริ่มใช้งาน

ต้องติดตั้ง Node.js เวอร์ชัน 22.13 ขึ้นไป และ npm ก่อน

```bash
git clone https://github.com/siriradahong/lab1_mibilewep.git
cd lab1_mibilewep
npm install
npm run setup
npm start
```

เปิด http://localhost:3000 และปล่อย Terminal ที่รันเซิร์ฟเวอร์ไว้ขณะทดลอง

`npm run setup` สร้างข้อมูลสินค้าตัวอย่างใหม่และสร้างหน้า SSG หากมีข้อมูลเดิมอยู่ คำสั่งนี้จะรีเซ็ตราคาสินค้าทั้งหมด

## หน้าที่ใช้ทดลอง

| URL | หน้าที่ |
| --- | --- |
| `/` | หน้าแรกและข้อมูลผู้จัดทำ |
| `/ssg/` | HTML ที่สร้างไว้ตอน build |
| `/ssr` | HTML ที่เซิร์ฟเวอร์สร้างทุกคำขอ |
| `/csr/` | หน้าเว็บที่ JavaScript ดึง JSON มาสร้างรายการสินค้า |
| `/api/products` | ข้อมูลสินค้า JSON |
| `/admin` | เปลี่ยนราคาสินค้าเพื่อเปรียบเทียบทั้งสามแบบ |

เมื่อแก้ราคา ให้รีโหลดแต่ละหน้า SSR และ CSR จะใช้ราคาใหม่ ส่วน SSG ต้องรัน `npm run build:ssg` แล้วรีโหลดอีกครั้ง

โทรศัพท์ที่เชื่อม Wi-Fi เดียวกับคอมพิวเตอร์เปิดผ่าน URL ที่แสดงใน Terminal บรรทัด “เปิดจากโทรศัพท์” ได้ การเปิดผ่าน HTTP ของ IP ใน LAN ไม่ใช่ Secure Context

## ไฟล์สำคัญ

- `public/index.html`: หน้าแรกพร้อมข้อมูลผู้จัดทำ
- `public/style.css`: สีและรูปแบบที่ใช้ร่วมกัน รวมการปรับสำหรับหน้าจอเล็ก
- `server.js`: Express, SSR, API และหน้าแก้ราคา
- `db/`: การเชื่อม SQLite และข้อมูลตัวอย่าง
- `lib/render.js`: แม่แบบ HTML ของ SSG และ SSR
- `scripts/build-ssg.js`: สร้างหน้า SSG
- `Lab01-answers.md`: คำตอบท้ายแลป ผลที่ตรวจได้ และรายการหลักฐานที่ต้องเก็บเพิ่ม

ไม่เก็บ `node_modules`, ฐานข้อมูลที่สร้างขึ้น และไฟล์ SSG ที่ build แล้วใน Git ให้สร้างด้วยคำสั่งด้านบน

โครงการนี้เป็นตัวอย่างสำหรับการเรียน ข้อมูลสินค้าเป็นข้อมูลสมมติ และหน้าแก้ราคาไม่มีระบบยืนยันตัวตน
